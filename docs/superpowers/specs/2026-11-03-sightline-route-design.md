# Sightline route design

## Intent
The owner found the dashboard and dossier versions generic and hard to look at. The page should be unique, calm and readable.

## Chosen approach
The page is the sightline: one transit-map line down the page. Each money movement is a stop with a plain-language headline, colour-and-role-coded addresses, attached warnings and inline evidence. The line ends at a terminus that lists what remains unknown.

References from clotheshoesandwoes/web-refs: Ciechanowski (colour as a glossary), Izakaya Sakura (one idea from the subject, restraint), Grilli Type (rules instead of boxes).

## Alternatives rejected
Card dashboard (generic), paper dossier with margin column (still dashboard structure, eyes jump between columns), exhibit ledger with separate diagram (sightline was one small figure instead of the page).

## Process
Built by the main model; Gemini reviewed screenshots, Claude reviewed code, accessibility and contrast. Both reviews' blockers were fixed before shipping.

## Constraints kept
Invented data only, validated responses, keyboard and screen-reader operation, WCAG AA text contrast in both themes, reduced motion, local fonts, no live-chain or AI claims.
