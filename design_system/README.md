# ChainSightline design system

## Idea

A line of evidence through complex activity. Calm investigation, not a cyberpunk dashboard.

## Reference direction

The owner supplied `clotheshoesandwoes/web-refs`. Use its discipline: one subject-driven idea, coherent type and spacing, restrained motion, and screenshot verification. The approved Living Evidence File direction is implemented: an editorial dossier, not a generic card dashboard.

## Product

Local-first read-only blockchain investigation workspace. Synthetic evidence is clearly labeled until live collection exists.

## Reading order

1. `identity.md`: brand, visual and interface principles.
2. `preferences.md`: owner feedback and product choices.
3. `open-items.md`: what is not implemented or verified.

Implementation: `apps/web/app/globals.css`, `apps/web/components/`, and `docs/assets/chainsightline-banner.svg`.

## Commands

`npm run dev` for local UI development. `npm start` for Docker launch after the launcher is installed. `npm test`, `npm run typecheck` and `npm run build` verify the slice.
